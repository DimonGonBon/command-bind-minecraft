# CommandKeys — Minecraft 1.21.4

Версия мода для Minecraft 1.21.4 и Fabric. Сборка: `gradle --no-daemon clean build` (нужны Java 21 и Gradle 9.2.0). Готовый JAR появится в `build/libs/`. Для бинда нажмите `K`, введите команду и выберите клавишу либо кнопку мыши. Боковые кнопки мыши поддерживаются; Shift и Ctrl игнорируются.
