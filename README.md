# CommandKeys для Minecraft

Клиентский Fabric-мод, который отправляет заданные команды по нажатию клавиш или кнопок мыши. Есть сборки для Minecraft **1.21.11** и **1.21.4**.

## Скачать

Откройте [последний релиз](https://github.com/DimonGonBon/command-bind-minecraft/releases/latest) и скачайте только файл для вашей версии игры:

| Minecraft | Файл |
| --- | --- |
| 1.21.11 | `CommandKeys-1.21.11-Fabric.jar` |
| 1.21.4 | `CommandKeys-1.21.4-Fabric.jar` |

Не устанавливайте оба JAR одновременно.

## Установка

1. Установите Fabric Loader для той же версии Minecraft через [установщик Fabric](https://fabricmc.net/use/installer/). Нужна Java 21.
2. Скачайте подходящий JAR из раздела [Releases](https://github.com/DimonGonBon/command-bind-minecraft/releases/latest).
3. При необходимости скачайте Fabric API той же версии Minecraft.
4. Переместите JAR мода и Fabric API в папку `mods` игрового профиля Fabric. Например, в Windows это `%appdata%\\.minecraft\\mods`.
5. Запустите нужный профиль Fabric.

## Использование

1. В игре нажмите **K**, чтобы открыть меню CommandKeys.
2. Введите команду, например `/spawn`.
3. Нажмите **«Выбрать клавишу/мышь»**, затем клавишу или кнопку мыши, на которую хотите назначить команду. Боковые кнопки отображаются как `Мышь 4`, `Мышь 5` и т. д.
4. Нажмите **«Добавить бинд»**. Бинды сохраняются автоматически в `config/commandkeys.json`.
5. Нажмите назначенную клавишу в игровом мире, чтобы отправить команду. Бинд срабатывает независимо от русской или английской раскладки.

Shift и Ctrl игнорируются при срабатывании: команда выполнится и при нажатии клавиши с зажатыми Shift или Ctrl. Бинды работают, когда игрок подключён к серверу и игровое меню закрыто. Команды отправляются от имени игрока; сервер проверяет права и доступность команды.

## Исходники и сборка

Исходники и отдельные Gradle-проекты находятся в `versions/1.21.11` и `versions/1.21.4`. Для локальной сборки нужны Java 21 и Gradle 9.2.0:

```sh
gradle --no-daemon clean build
```

GitHub Actions собирает обе версии при каждом push и PR. Последний релиз прикладывает отдельный JAR для каждой версии Minecraft.
